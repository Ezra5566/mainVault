## 3. The Math Underneath (06-Math / class_AI math notes)

- [[linear_algebra_vectors]] — vectors, dot products, the geometry of features & embeddings.
- [[matrices]] — matrix algebra, the shape of every neural‑net layer.
- [[calculus_basics]] — derivatives and gradients, *why* we update weights.
- [[probability_and_statistics]] — distributions, expectations, uncertainty, metrics.
- Master references: [[06-Math/Mathematics for ML]], [[06-Math/Calculus/math_formulas_comprehensive]], [[06-Math/Calculus/mathematics_master]]

## 7. How to Study This Cluster

1. **Weeks 1–2:** read [[AI_Foundations_Weeks_1-2]] + the concept notes it links. No code yet — build the *mental map*.
2. **Weeks 2–4:** work [[Mathematics_for_AI_Weeks_2-4]] alongside [[linear_algebra_vectors]] / [[matrices]] / [[calculus_basics]] / [[probability_and_statistics]].
3. **Weeks 4–6:** [[Programming_for_AI_Weeks_4-6]] → then read [[Python for AI]] and [[Python]] (full language & stdlib reference); do the first project in them.
4. **Weeks 6–8:** [[Machine_Learning_Core_Module]] → [[Deep_Learning_Weeks_6-8]].
5. **Weeks 8–9:** [[Generative_AI_Weeks_8-9]] → read [[AI Engineering]] and [[Prompt Engineering]]; build the RAG + LLM assistant project.
6. **Continuous:** [[AI Portfolio Strategy]] — ship the projects, document them, link them into your résumé ([[Industry_Skills_Resume_Portfolio]]).
