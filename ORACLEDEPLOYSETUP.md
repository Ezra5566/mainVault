Here is your step-by-step checklist to set up your Spree Node.js and MongoDB backend on Oracle Cloud Frankfurt without errors.
## Phase 1: Oracle Cloud Sign-Up & Network Prep

* Register the Account: Use the exact billing address and country of your credit card during registration to avoid immediate fraud blocks.
* Select the Home Region: Double-check that you select Europe (Frankfurt) as your Home Region before completing registration.
* Create a Virtual Cloud Network (VCN): Use the "Start VCN Wizard" in the OCI dashboard to automatically build a public network with basic internet routing.
* Configure Security Lists (OCI Firewall): In your VCN's Public Security List, add an Ingress Rule for Port 443 (HTTPS) from source 0.0.0.0/0 so users can access your store. Leave Port 27017 (MongoDB) closed to the public.

## Phase 2: Server Provisioning

* Launch the VM Instance: Go to Compute -> Instances -> Create Instance.
* Select Image and Shape: Choose Ubuntu 24.04 LTS (ARM64) as your OS. Change the shape to Ampere (VM.Standard.A1.Flex).
* Allocate Maximum Free Resources: Slide the configuration to exactly 4 OCPUs and 24 GB of RAM.
* Set Boot Volume Size: Change the custom boot volume size to 100 GB to give your site plenty of headroom.
* Save SSH Keys: Download the private and public SSH key files generated by Oracle onto your local machine in China. Launch the instance.

## Phase 3: Server Optimization (From China via SSH)

* Connect via SSH: Open your terminal and connect to your new instance using your downloaded private key (ssh -i your_key.key ubuntu@your_server_ip).
* Update System Packages: Run sudo apt update && sudo apt upgrade -y to pull down the latest Linux security patches. [1] 
* Open Ubuntu Firewall Ports: Run the following commands to ensure OS-level traffic flows smoothly:
* sudo ufw allow 22/tcp (Ensures you don't lock yourself out of SSH)
   * sudo ufw allow 443/tcp (Web traffic)
   * sudo ufw enable

## Phase 4: Installing Your ARM-Compatible Stack

* Install Docker & Docker Compose: Install Docker using Ubuntu's official guide to ensure you get the native ARM64 engine.
* Verify ARM64 Container Compatibility: In your project's docker-compose.yml, verify that your node and mongo image tags natively support arm64/v8 architecture.
* Set Up Environment Variables: Configure your Spree production environment file (.env), explicitly pointing its database connection string to mongodb://localhost:27017 or your internal container network link.
* Launch the Stack: Run docker compose up -d to pull the ARM images and run Spree and MongoDB silently in the background.

## Phase 5: Cloudflare & Kenya Network Speed Optimization

* Create a Free Cloudflare Account: Add your e-commerce domain name to Cloudflare.
* Update Domain Nameservers: Log into your domain registrar and point your domain's nameservers to the custom nameservers provided by Cloudflare. [2] 
* Point DNS to Oracle Cloud: Inside Cloudflare's DNS panel, create an A Record pointing your domain name directly to your Oracle Frankfurt public IP address.
* Enable Cloudflare Proxy ("Orange Cloud"): Ensure the proxy switch is toggled to active. This immediately enables Cloudflare's Nairobi / Mombasa edge caches, protecting your origin backend server and serving static product pages instantly to Kenyan mobile networks.
