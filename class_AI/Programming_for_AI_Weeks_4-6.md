# Programming for AI (Weeks 4–6)

**Goal:** Students can actually build AI projects.

## Language
- **Python** – primary language for AI development.

## Core Concepts
- **Variables & Data Types**
  - Numbers, strings, booleans
  - Type conversion
- **Functions**
  - Definition, arguments, return values
  - Lambda functions
- **OOP Basics**
  - Classes, objects
  - Inheritance & polymorphism
- **Data Structures**
  - Lists, tuples, dictionaries, sets
  - List comprehensions
- **APIs**
  - Importing standard libraries
  - Using third‑party packages
  - Basic HTTP requests (requests library)

## Essential Libraries
- **NumPy** – array operations, linear algebra utilities
- **Pandas** – data manipulation, DataFrames
- **Matplotlib** – data visualization (plots, histograms)
- **Jupyter Notebook** – interactive coding environment for exploration and presentation

## Mini Project
- **Analyze student performance data**
  - Load a CSV of grades
  - Compute statistics (mean, median, variance)
  - Visualize score distributions with Matplotlib
  - Summarize findings in a short notebook

> **Tip:** Encourage students to use virtual environments (`venv` or `conda`) to manage package dependencies.
