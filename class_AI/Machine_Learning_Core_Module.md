# Machine Learning (Core Module)

**Focus:** Core concepts and algorithms that form the backbone of AI systems.

## Topics
- **Supervised Learning**
  - Definition and workflow
  - Train‑test split, validation strategies
- **Unsupervised Learning**
  - Clustering techniques
  - Dimensionality reduction
- **Reinforcement Learning**
  - Agent‑environment interaction
  - Reward signals and policy learning

## Core Algorithms
| Category | Algorithms |
|----------|------------|
| **Regression** | Linear Regression, Logistic Regression |
| **Tree‑based Models** | Decision Trees, Random Forest |
| **Clustering** | K‑Means, Hierarchical Clustering |
| **Support Vector Machines** | SVM (linear & non‑linear kernels) |

## Evaluation Metrics
- **Accuracy**
- **Precision**
- **Recall**
- **F1 Score**
- **ROC‑AUC** (optional)
