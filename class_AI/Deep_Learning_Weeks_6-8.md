# Deep Learning (Weeks 6–8)

**Focus:** Neural networks and modern deep learning techniques.

## Topics
- **Neural Networks**
  - Perceptron, activation functions
  - Feed‑forward networks, universal approximation
- **Training Dynamics**
  - Forward propagation
  - Back‑propagation
  - Gradient‑based optimization
- **Convolutional Neural Networks (CNNs)**
  - Convolution, pooling, padding
  - Common architectures (LeNet, AlexNet, ResNet)
- **Recurrent Neural Networks (RNNs)**
  - Sequence modeling, hidden state
  - LSTM, GRU variants
- **Transformers**
  - Self‑attention mechanism
  - Encoder‑decoder architecture
  - Applications (NLP, vision, multimodal)

## Recommended Framework
- **PyTorch** – primary API for research and prototyping
- **TensorFlow/Keras** – optional for production pipelines

## Hands‑On Projects
1. **Image Classification**
   - Dataset: CIFAR‑10 or a small custom image set
   - Tasks: Data augmentation, model design, training loops, evaluation
2. **Chatbot**
   - Use a sequence‑to‑sequence or transformer‑based model
   - Implement tokenization, training on conversational data, inference
   - Evaluate with perplexity and human interaction

> **Tip:** Emphasize experimenting with hyperparameters (learning rate, batch size) and visualizing training curves.
